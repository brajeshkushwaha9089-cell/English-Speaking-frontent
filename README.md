# 🌐 Bolo English - Frontend Web Application

Interactive English conversation and speaking practice frontend built with modern Web Speech API, real-time voice synthesis, and dynamic AI assistant integrations.

---

## ✨ Highlights
- 🎙️ Hands-free Live Voice Bot (4 personas: Riya, Vikram Sir, Priya Ma'am, Kabir)
- 📚 Vocabulary Book & Stories with Hindi pronunciations & audio
- ⚡ 100% responsive for Desktop & Mobile browsers
- 🔗 Connects to Backend API on Render or runs standalone with client keys

---

## 🚀 Deploy to Vercel (1-Click)

1. Go to [vercel.com](https://vercel.com) and click **Add New...** -> **Project**.
2. Import `English-Speaking-frontent`.
3. Keep default settings:
   - **Framework Preset**: *Other*
   - **Root Directory**: `./`
4. Click **Deploy**!
5. Once deployed, open your live URL on desktop or mobile Chrome/Edge!

---

## ⚙️ Configuration & Backend Connection

By default, the app can connect to your deployed Render backend API (`https://bolo-english-backend.onrender.com` or custom):
- Open **Settings (⚙️)** in the web app.
- Enter your backend URL under **Backend API Server (Render / Local)** and click **Save**.
- Click **⚡ Test Backend Connection** to confirm.
